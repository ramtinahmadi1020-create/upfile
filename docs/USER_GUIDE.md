# User Guide

## Home page
- Drag & drop or click "Select File" to upload.
- Each file gets its own progress card.

## Progress card
- Percent 0-100
- Speed in MB/s
- Uploaded / total size
- ETA
- Chunks done / total

## Large files
- Files > 5 GB show a warning: "This file is large and upload may take a while".

## Resume
- If upload interrupted, re-select same file; the app detects matching checksum and resumes missing chunks.

## Links
- After upload, a row appears with name, size, link, copy button.
- Click copy to copy link; toast confirms.

## View / Download
- Open /f/{id} to view inline (images, video).
- Open /d/{id} to download.

## Language
- Click EN/FA button in header to switch instantly.

## Profile
- Register/login with username + password.
- Logout button clears session.

## FAQ
- Max file size 50 GB.
- Chunk size 40 MB.
- Up to 3 files upload in parallel.
